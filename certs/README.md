# Сертификат для MAX API

`russian_trusted_root_ca.pem` получен 23.10.2026 по HTTPS из официального источника:
https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

SHA-256 DER-сертификата:
`d26d2d0231b7c39f92cc738512ba54103519e4405d68b5bd703e9788ca8ecf31`

Официальная документация MAX требует этот корень для `platform-api2.max.ru`:
https://dev.max.ru/docs-api

В `.env` задаётся `KORSIK_MAX_CA_FILE=certs/russian_trusted_root_ca.pem`. Этот путь работает из корня проекта и внутри контейнера `/app`. MAXClient добавляет корень к стандартным CA только в своём SSL-контексте. Проверка цепочки и имени сервера остаётся включённой. Хранилища Windows и других HTTP-клиентов не меняются.

Перед обновлением сертификата скачать новый файл только из официального источника, проверить его формат, срок и отпечаток. Не отключать TLS-проверку.
