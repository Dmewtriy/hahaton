# Кандидат контракта NLP → backend → руководитель

Это подготовленный адаптер, который нужно согласовать с ML-командой. Существующий порт `ml.py` и его `/v1/answer`, `/v1/analyze`, индексация документов сохранены. Алгоритмы RAG/NLP в backend не реализуются.

Внутренний endpoint: `POST /api/integrations/nlp/events`. Авторизация — `Authorization: Bearer <KORSIK_ML_TOKEN>`. Без настроенного ключа возвращает 503. Через временный публичный gateway endpoint закрыт; сервис ML подключается по доверенному адресу backend/Docker-сети.

```json
{
  "schema_version": "1",
  "event_id": "analysis-event-unique-id",
  "answer_id": "backend-survey-answer-id",
  "manager_signal": "meeting_recommended",
  "result": {
    "sentiment": "negative",
    "risk": "high",
    "topics": ["adaptation"],
    "explanation": "Объяснение для уполномоченного HR",
    "needs_hr": true,
    "processor_version": "team-nlp/1.0"
  }
}
```

Метка: `none` либо `meeting_recommended`. Backend привязывает ответ к сотруднику, определяет текущего руководителя сам и создаёт один MeetingSignal для анализа. Передавать manager_id, MAX user ID или готовый произвольный текст руководителю не нужно и нельзя. Повтор event_id с тем же телом возвращает duplicate; с другим телом — 409. Неизвестный answer_id — 404. Порядок/версии всех принятых внешних результатов сохраняются в NlpEvent; актуальная проекция — FeedbackAnalysis. Предыдущая проекция сохраняется перед заменой.

Руководителю отправляется нейтральная рекомендация личной встречи с именем сотрудника и подразделением. Исходный текст, объяснение, риск и темы NLP в уведомление не попадают. Если руководитель не назначен или недоступен, сигнал ждёт назначения. Перед отправкой права и назначение проверяются повторно. Это рекомендация, не кадровое решение.

Для обращения HR применяется серверная политика escalation_rules: enabled, минимальный риск, список тем. Метка встречи и необходимость обращения HR — разные поля. Числа дашбордов, дайджестов и CSV/XLSX считает backend из сохранённых данных.

Для согласования остаются: окончательное имя и формат метки, синхронный ответ или callback, словарь тем, правила версий/повторного анализа и секреты интеграции. Изменения локализуются в адаптере; менять сценарии, UI руководителя и модель доступа не потребуется при сохранении смысла сигнала.
